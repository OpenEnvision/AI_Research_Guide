# 进阶专题：从任务定义到可检验的研究

检索、推荐、图学习、时间序列、因果推断和概率建模，既是独立研究方向，也会成为大模型、机器人和科学研究的方法基础。本页补充[研究方向地图](directions.md)，重点说明每个专题如何起步、应该比较什么，以及结论的适用边界。

先选择一个专题，再按需要回顾[基础知识](basics.md)中的概率、线性代数、优化与数据划分。第一遍阅读先抓住核心概念，并手工解释一个例子。下文的实践建议可按需尝试，不必完成后才能继续阅读。系统学习见[课程与 MOOC](courses.md)，需要实现时再查[研究工程](engineering.md)。

## 按任务选择专题

| --- | --- | --- |

| 给用户排序候选内容 | 推荐系统 | 时间划分、候选集定义、热门基线与冷启动分析 |

<a id="retrieval"></a>

## 信息检索：候选召回、排序与证据

检索的目标是为查询返回相关对象，生成答案是后续可选环节。先区分词法检索、稠密向量检索、候选重排与 RAG；一个组件得分更高，并不意味着整个问答系统的表现更好。先修包括文本处理、向量运算、概率和基本评价指标。

**核心概念。** 词法方法根据共有词项打分，稠密检索比较学习到的表示，重排器再对较小候选集作更细致判断。相关文档若不在候选集中，仅靠重排无法将它找回。

**实践建议。** 为一小批有明确需求的查询整理文档与相关性判断，保留 TF-IDF 或 BM25 基线；在同一语料、候选数与硬件条件下加入一个稠密检索或重排组件。记录索引版本、切块、查询处理、检索深度与延迟。查询应尽量代表目标需求，不能只挑模型容易处理的关键词。

**评价与边界。** Recall@k 衡量相关对象进入前 k 个结果的比例；MRR 关注首个相关结果是否靠前，nDCG@k 则结合相关性增益与位置折扣。同一前 k 个集合内的排序变化，可能改变后两者，却不改变 Recall@k。还应写明相关性等级、无相关文档查询和并列分数的处理。相关性标注往往不完整；未标注不必然意味着不相关。若接入生成器，再检查答案正确性、引用支持与不可回答问题，不能以检索指标代替回答评价。

- **[Introduction to Information Retrieval](https://nlp.stanford.edu/IR-book/)** — 作者提供的英文教材，学习倒排索引、词项权重、概率检索与评价。先实现一个小型排序器，再核对评价章节中的假设。
- **[BEIR](https://github.com/beir-cellar/beir)** — 官方基准实现，需 Python 与检索基础。用于学习跨数据集检索评价；先选择一个规模适当的任务并记录语料、查询与 qrels 版本，不能把跨任务均值当作所有领域的保证。

## 推荐系统：交互记录不等于真实偏好

推荐研究包含候选生成、排序、序列建模、冷启动和长期反馈。点击、评分与购买由曝光、位置和用户选择共同形成；未发生的交互既可能是不喜欢，也可能是没有被看到。先修包括矩阵分解、分类/排序损失、概率与数据处理。

**核心概念。** 矩阵分解用低维向量表示用户和物品，通过向量交互预测分数。模型学习的是已记录的曝光与反馈过程，预测分数并不是对个人内在偏好的直接测量。

**实践建议。** 在允许使用的交互数据上比较热门推荐、简单协同过滤或矩阵分解，再加入一个目标模型。先写清预测时点：哪些用户历史、物品属性和候选物品当时已经可用。按时间和任务设计训练、验证、测试，分别分析新用户、新物品与已有用户。

**评价与边界。** 固定候选集合、负例采样方式、已交互物品过滤与指标截断位置。全量候选和采样候选的 Recall/nDCG 不能直接混合比较；评分预测误差与排序质量也是不同目标。离线分数不能单独证明用户满意度或长期收益。线上实验涉及真实用户时，应另行设计分流、干预与影响监测。

- **[D2L · 推荐系统](https://d2l.ai/chapter_recommender-systems/index.html)** — 英文教材专题，介绍推荐任务、矩阵分解与相关模型。建议重做一次数据划分并解释结果变化。
- **[RecBole 官方代码](https://github.com/RUCAIBox/RecBole)** — Python/PyTorch 研究框架，需 ML 与推荐基础。学习统一数据格式和评价配置；保存完整配置与版本，比较时核对数据和负采样协议。

## 图学习：先说明图怎样产生

节点、边及其属性表达了什么，决定模型获得了哪些信息。节点分类、链接预测与图分类需要不同评价单位；同一张图上的传导学习，与面向新节点或新图的归纳学习，也不能混为一谈。先修包括图算法、线性代数、概率和神经网络。

**核心概念。** 消息传递层聚合邻居信息，再更新节点表示；多层传播会扩大节点能够获得的信息范围。因此，构图改变了模型输入，不只是改变一幅可视化图。

**实践建议。** 先建立只使用节点属性的模型，再加入邻居统计或消息传递。保留图构建、方向、自环、采样和特征处理规则。链接预测要说明划分时哪些边被移除、负例如何产生；时间图中的未来边不能被提前用作消息传递的信息。

**评价与边界。** 使用数据集规定的划分与评估器，检查目标标签是否通过节点特征、边构建或预处理泄漏。按节点、图或时间报告结果；在可行时分析结构扰动、低度节点和异配关系。移除边后的性能变化可以帮助判断模型对边信息的依赖，不能单独证明学到了某种领域机制。

- **[Stanford CS224W](https://web.stanford.edu/class/cs224w/)** — 英文大学课程，介绍图表示、GNN 与图相关任务。需要编程、概率与线性代数；当期讲义和历史材料的公开范围分别核对。
- **[OGB · Node Property Prediction](https://ogb.stanford.edu/docs/nodeprop/)** — 官方任务和划分说明。建议用同一数据版本比较属性基线与简单 GNN，记录图可见性和评估器。

<a id="time-series"></a>

## 时间序列：把预测时点写进实验

先区分预测、时序分类、异常检测和插补；它们对可用未来信息的要求不同。预测任务要定义观察窗口、预测步长、频率、更新周期，以及外生变量何时可获得。先修包括统计、回归、时间索引与基本信号概念。

**核心概念。** 预测以特定时点可获得的信息为条件。季节性朴素预测复用最近一次相应季节的观测，帮助判断复杂模型是否学到了超出周期重复的信息。

**实践建议。** 从 naive 或 seasonal-naive 基线开始，再比较一个统计模型或滞后特征模型。采用滚动预测起点，在每个训练窗口内拟合归一化与特征变换；调参也应遵守时间顺序。若训练标签的预测窗口跨入验证期，应按信息重叠设计间隔或清除规则，而非机械套用固定 gap。

**评价与边界。** 分别记录逐步长 MAE/RMSE、不同序列的聚合权重，以及区间预测的覆盖与宽度。真实值接近零时，MAPE 会失稳；不同量纲的误差不宜直接平均。多个滚动窗口存在重叠与相关性，不能当作任意数量的独立样本。数据修订与事后得到的外生变量也可能引入未来信息。

- **[Forecasting: Principles and Practice · 工具箱](https://otexts.com/fpp3/toolbox.html)** — 作者提供的英文教材，示例使用 R。重点学习基线、误差、预测区间与时间序列交叉验证。
- **[sktime](https://www.sktime.net/)** — Python 官方文档与示例。建议完成一个滚动回测，并把信息可用时点和逐预测步结果写入报告。

## 因果推断：识别先于估计

预测“谁更可能出现某个结果”，与估计“改变某项处理会怎样影响结果”是不同任务。先定义处理、结果、目标人群、时间零点和目标效应，再讨论随机试验或观察性数据是否能够识别它。需要概率、统计与回归基础；入门时宜先做模拟练习，再考虑对真实的高风险场景作因果判断。

**核心概念。** 选择辅导的学生，在辅导开始前就可能不同于未选择者。直接比较两组成绩，会把干预与选择差异混在一起；识别论证说明哪些设计或假设能够把目标效应与这种差异区分开。

**实践建议。** 从一个已知数据生成过程的模拟系统出发，画出因果图，改变混杂强度和样本量；比较粗关联、满足假设时的调整估计，以及故意遗漏混杂变量后的结果。说明一致性、可交换性与正值性等假设在当前问题中意味着什么，并检查估计器与目标效应是否对应。重复生成数据，估计偏差与区间覆盖比例，并报告重复次数和 Monte Carlo 不确定性。一次数据生成只能给出一次估计误差与是否覆盖真值，不能证明重复抽样下的性质。

**评价与边界。** 保存真实模拟效应、估计偏差、区间覆盖与失败条件。对观察性研究，写明哪些假设不能从数据本身检验；敏感性分析说明结论依赖什么，不能证明不存在未测量混杂。反事实框架、因果图与软件可以帮助组织推理，不能自动替代识别论证。

- **[Causal Inference: What If](https://miguelhernan.org/whatifbook)** — Hernán 与 Robins 的作者提供的英文教材及代码入口。学习处理、反事实、试验与观察性研究，先完成一个模拟例子的目标效应说明。
- **[Brady Neal · 因果推断课程](https://www.bradyneal.com/causal-inference-course)** — 英文课程与讲义。建议将同一问题写成因果图与潜在结果表述，列出识别所需条件。

## 概率建模与贝叶斯推断：检查假设和预测

先写数据的生成过程：未知量是什么，观察如何产生，哪些量之间独立或共享结构。区分似然、先验、后验与后验预测；参数不确定性和未来观测的波动也不是同一个量。先修包括概率分布、条件概率、微积分和数值计算。

**核心概念。** 对硬币模型，先验描述正面概率的不确定性，似然描述给定该概率时的投掷观测，后验则是在观察之后更新的不确定性。预测下一次投掷时，后验预测对参数不确定性作平均。

**实践建议。** 从具有解析解的简单模型起步，再实现一个小型层级模型。用先验预测检查先验是否产生合理数据；比较解析结果与数值推断，记录链、初始化、采样预算与诊断。使用真实数据时，再进行后验预测检查和适合任务的留出评价。

**评价与边界。** 同时报告模型假设、先验敏感性、推断诊断与预测误差。对 MCMC 检查链的混合、有效样本量与适用的收敛诊断；HMC 还应检查发散等信息。良好的诊断结果增加了数值推断的可信度，但不能证明模型假设正确。贝叶斯可信区间的解释依赖模型与先验，不能直接改写为频率学置信区间的覆盖陈述。

- **[Probabilistic Machine Learning · Kevin Murphy](https://probml.github.io/pml-book/)** — 英文教材系列，学习概率模型、推断与学习。建议把一个模型的生成过程、目标函数和计算方法连起来。
- **[PyMC · Learn](https://www.pymc.io/projects/docs/en/stable/learn.html)** — 官方 Python 贝叶斯建模学习资料。具备概率与 Python 基础后，完成一个包含预测检查与诊断的 notebook，并固定依赖版本。

<a id="audio"></a>

## 音频与语音：数据处理本身就是协议

语音识别、语音合成、说话人任务与音频事件分类，输入和成功条件不同。先理解采样率、通道、波形、频谱、分段与长度；重采样应实际变换信号，不能只改文件的采样率标签。需要 Python、基础信号处理与深度学习知识。

**核心概念。** 波形记录振幅随时间的变化，频谱图描述短时间窗内的频率成分。语音识别将音频映射为 token 序列，信号表示与转写规则共同定义了任务。

**实践建议。** 在许可清楚的小数据集上运行预训练基线，再比较一种数据增强、分段或适配方案。按任务隔离说话人、会话或录音来源，避免同一长录音的片段跨划分。保存文本归一化、标点、大小写、分词与参考转写版本。

**评价与边界。** ASR 可按协议报告 WER/CER，并保留替换、删除和插入错误；中英文的 token 单位应明确。音频分类报告逐类结果与噪声条件，合成任务需另行设计自然度、可懂度与说话人相似性评价。低转写错误率不能单独证明说话人公平性、隐私保护或对所有口音稳健。

- **[Hugging Face Audio Course](https://huggingface.co/learn/audio-course/chapter0/introduction)** — 英文官方课程，需 DL 与 Transformer 基础，覆盖音频处理、分类、ASR 与文本转语音。建议先完成一个带错误分析的基线。
- **[LibriSpeech](https://www.openslr.org/12)** — 官方数据入口，主要是英语朗读语音。建议记录数据子集与说话人划分；朗读语音结果不能直接代表会议或嘈杂对话。

<a id="geometry"></a>

## 三维视觉与几何：坐标约定决定结果

相机标定、多视图几何、深度、点云配准与三维重建需要几何知识，不能只看渲染图是否逼真。先掌握投影、内外参、齐次坐标、刚体变换、尺度与遮挡；明确世界到相机还是相机到世界、左手还是右手坐标以及长度单位。

**核心概念。** 相机把三维点投影到图像位置，深度信息随之丢失。恢复几何需要视角、运动或测量提供额外约束；看起来合理的重建，仍可能具有错误的尺度或形状。

**实践建议。** 用有已知变换的合成点云核查变换方向，再做 ICP 配准；记录初值、对应点阈值、下采样与噪声。对多视图重建，保留相机、输入视角和留出视角，分别检查几何结构与图像重建质量。

**评价与边界。** 按任务报告旋转/平移误差、配准成功、重投影误差或几何距离，并注明对齐与尺度处理。ICP 可能收敛到局部解；小残差不保证对应关系正确。新视角渲染质量、表面几何准确性和机器人可用的深度是不同主张，需要分别验证。

- **[Computer Vision: Algorithms and Applications](https://szeliski.org/Book/)** — Szeliski 的作者提供的英文教材，第二版系统介绍视觉与几何知识。建议先推导并验证一个投影或标定例子。
- **[Open3D · ICP registration](https://www.open3d.org/docs/release/tutorial/pipelines/icp_registration.html)** — 官方教程，需 Python 与线性代数。对已知变换比较初始误差与配准误差，再改变噪声和初值定位失效条件。

<a id="theory"></a>

## 学习理论与优化：把成立条件写完整

理论研究可以分析样本复杂度、泛化、优化收敛、表示能力或计算限制。经验曲线可以启发命题，但不能充当证明。先补概率不等式、线性代数、微积分、凸性和基本证明方法；根据目标命题再学习相应工具。

**核心概念。** 泛化界在特定条件下联系样本表现与总体表现；优化界讨论向某个目标最优值推进的程度。抽样过程或目标改变后，需要重新检查假设，不能直接沿用结论。

**实践建议。** 选择一条简单结论，明确样本如何产生、假设类或目标函数是什么、结论对哪些随机性成立。例如比较有限假设类的一致收敛论证，或推导满足光滑性等条件的梯度下降法的下降界；把每一步使用的条件标出来，再构造违反条件的例子。

**评价与边界。** 区分总体风险与经验风险、期望界与高概率界、渐近结论与有限样本结论。界可能保守，不能不经额外论证就用它预测实际模型排名。优化目标下降也不能直接证明泛化有所改善。给出数学对象、量词、常数/量级、证明、反例与数值说明；数值结果只检验指定实例。

- **[CMU 10-701 · Learning Theory 讲义存档](https://www.cs.cmu.edu/~tom/10701_sp11/lectures.shtml)** — 英文课程资料，包含 PAC learning、mistake bounds 等主题。适合已有概率与证明基础者完成一次带条件标注的推导。
- **[An Introduction to Statistical Learning](https://www.statlearning.com/)** — 作者提供的英文教材及 R/Python 资源。适合作为统计学习的实证补充：把重采样、复杂度和测试误差与理论中的对象对应，不将它作为全部理论证明的替代。

## 把一个专题做成可评审的研究计划

无论选择哪一节，先完成四份相互对应的材料：问题与相关工作表、数据与信息可用性说明、基线和对照协议、结果与限制报告。不要同时更换数据、模型和评价，再将差异归因于其中一个因素。

| 里程碑 | 需要检查的内容 | 继续的条件 |
| --- | --- | --- |
| 定义任务 | 输入、目标、评价单位与实际使用情境 | 能手工判断少量样例的好坏 |
| 跑通基线 | 划分、预处理、指标和最小可运行实现 | 指标计算可核查，结果可重新生成 |
| 提出问题 | 文献中的差异、可反驳假设与预算 | 已区分探索和最终评价 |
| 做受控比较 | 对照、运行差异、错误类型与成本 | 结果包含失败情形和不确定性 |
| 交付材料 | 配置、来源、结果表、图表与限制 | 他人能理解结论由哪些证据支持 |

具体实验设计与案例见[科研方法](research-methods.md)，数据和指标细节见[数据集与评测](datasets.md)。涉及公平、隐私、鲁棒性、解释与真实使用场景时，结合[可信与负责任 AI](responsible-ai.md)设计评价。
