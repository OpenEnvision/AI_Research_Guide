# 大语言模型：理解、生成、推理

日常使用的对话模型背后，有一系列值得研究的问题：文本怎样转化为模型可以处理的表示，模型从哪些数据中学习，训练方式为什么会影响回答，以及怎样判断模型是否有所改进。

大语言模型从文本中学习表示与生成规律，通过指令、示例和上下文处理问答、摘要、代码等任务。数据、模型结构与训练方法共同影响这些能力；到了使用阶段，上下文怎样组织、推理计算怎样分配，也成为研究的一部分。

## 初学者的阅读路线

先理解分词、词嵌入、Attention 和下一个 token 的交叉熵，再理解批量训练与推理时逐步生成文本之间的联系。[基础知识](basics.md)中的线性代数、条件概率与反向传播足以开始。结合小模型的结构图与学习目标阅读即可入门，无需训练大模型。

读论文时，先区分四种操作：

| 操作 | 改变了什么 | 阅读时关注什么 |
| --- | --- | --- |
| 预训练 | 从广泛的训练语料中学习模型权重 | 目标函数、数据配比与计算量 |
| 微调或偏好训练 | 权重根据示范或反馈进行适配 | 数据来源、奖励或偏好定义、更新哪些参数 |
| 上下文学习 | 当前输入提供指令或示例 | 提示格式、示例选择与上下文长度 |
| 检索或工具调用 | 外部信息进入计算过程 | 检索质量、来源权限及结果怎样影响回答 |

下一个 token 预测提供训练目标，并不保证事实正确。Attention 将可见位置的信息组合起来，它的权重本身不能证明答案为什么正确。留出文本上的语言模型损失与特定任务上的表现存在关联，但损失下降和能力提高仍需分别测量。

## 分词、表示与模型结构

文本经过 tokenizer 转成 token 序列，再映射成向量。[Transformer](https://arxiv.org/abs/1706.03762) 用 Attention 组织不同位置之间的信息，自回归语言模型根据已有上下文预测后续 token。[BERT](https://arxiv.org/abs/1810.04805) 则通过预测被遮住的内容学习双向表示。模型结构与训练目标的不同，带来了不同的语言表示和使用方式。

[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) 介绍模型、tokenizer、数据处理与微调；[LLMs from Scratch](https://github.com/rasbt/LLMs-from-scratch) 配合代码实现分词、Attention 和语言模型训练。[CS224N](https://web.stanford.edu/class/cs224n/) 围绕自然语言处理讲解语言表示、神经网络与具体任务。相关数学与深度学习内容见[学习基础知识](basics.md)。

## 预训练与 Scaling

预训练利用大量数据优化模型参数。数据的来源、质量和配比，模型规模、训练目标与计算预算，都影响模型学到什么。Scaling 研究这些因素与模型表现之间的关系，也研究怎样用较小规模的实验指导更大规模的训练。

[Stanford CS336（2025）](https://cs336.stanford.edu/spring2025/) 围绕语言模型的实现与训练，覆盖分词、模型、数据处理、Scaling 和训练系统，配有实现作业。[pretrain 和 scaling 作为一种方法论和科学观](https://jiaxuanzou0714.github.io/blog/2026/pretrain-scaling-methodology-scientific-perspective/)讨论训练规模、数据、稳定性与问题选择；[Scaling 相关笔记](blogs.md#zou)还包括实验组织与外推。

## 后训练与推理

后训练利用示范、偏好或奖励调整模型的行为。指令微调学习如何响应要求，偏好学习与强化学习进一步利用回答之间的比较或任务反馈。[LoRA](https://arxiv.org/abs/2106.09685) 从参数更新方式入手，减少适配模型时需要训练的参数量；奖励、策略梯度与优化方法则与[强化学习](rl.md)相连。

这里的 inference 指运行已训练模型的过程，reasoning 则指需要通过具体任务评估的推理能力。推理阶段的研究涉及上下文、搜索、验证和计算分配。同一个模型可以产生多个候选、调用外部工具，或根据反馈修改答案；相应的时间和计算成本也会变化。工具交互见 [Agent](agent.md)，图像与语言的结合见[多模态](multimodal.md)。

## 如何设计一项可检验的语言模型研究

- **研究问题与对照：** 明确待检验的分词、数据配比、适配方法或推理策略，并在其余可比条件下控制任务、数据和计算预算。区分预训练、监督微调、偏好学习和上下文学习；改变多个环节时，分别设计组件对照。
- **评价协议：** 记录模型与数据版本、提示、解码、上下文长度、答案提取和评分器。报告任务级结果、错误类型与时间或 token 成本，检查训练与评测数据的重叠，并说明哪些数据污染风险尚不明确。
- **结论边界：** 生成流畅、遵循指令、事实准确和推理正确需要不同证据。LoRA 减少可训练参数，并不意味着总显存占用、推理成本或模型表现也会按相同比例改善。
