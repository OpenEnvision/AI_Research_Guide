# AI 研究方向与问题地图

选择研究方向，可以先从自己想理解的问题出发：有哪些可用信息，系统需要预测什么或完成什么任务，怎样的证据才有说服力？下面的领域彼此交叉。演示可以启发问题，但其结论是否成立，仍需结合数据、假设与评价方法判断。

## 模型怎样理解与生成

- **[大语言模型](llm.md)**：模型怎样从文本中学习，训练、数据和计算怎样影响它的能力。
- **[计算机视觉](vision.md)**：从图像中识别物体、确定位置，进一步理解场景和三维结构。
- **[多模态](multimodal.md)**：结合图像、语言等不同来源的信息，支持理解与问答。
- **[生成模型](generation.md)**：怎样学习分布，按条件或无条件生成文本、图像、音频等样本。

## 模型怎样行动

- **[Agent](agent.md)**：给模型工具和环境，观察它怎样把一项任务做完。
- **[强化学习](rl.md)**：当前行动会影响后续状态，怎样利用反馈学习决策。
- **[世界模型](world-model.md)**：学习环境动态的预测模型，可在给定行动时预测变化，并用于表示、规划或控制。
- **[具身智能](embodied.md)**：机器人怎样根据观察选择并执行动作，在真实环境中完成任务。

这些方向相互关联。机器人可以结合视觉、生成模型和 RL，Agent 也可以借助 RL 学习。阅读交叉主题时，可以围绕自己的问题选择后续内容。

## 模型怎样高效运行并服务具体领域

- **[效率与系统](systems.md)**：为什么程序慢、显存不够，怎样在质量、延迟和成本之间做选择。
- **[AI 交叉学科](ai4x.md)**：怎样把 AI 方法与科学、医学或工程问题结合，并尊重各领域的证据要求。

每页介绍核心概念、入门方法与延伸阅读。查找单篇论文可用[论文选读](papers.md)，了解研究者观点可用 [Lookout](lookout.md)。课程、基准、论文和评论分别帮助理解主题、定义测试、呈现证据和解释观察，引用时应辨认它们承担的角色。

## 用任务与证据比较方向

以下比较是选题导航，不是互斥分类。一个研究问题可以同时涉及表示学习、生成、决策和系统；课程的先修要求与实验预算，比方向名称更直接地决定如何起步。

| 方向 | 典型研究问题 | 入门研究中需要核对的证据 |
| --- | --- | --- |
| 语言模型与 NLP | 表示、数据、适配、生成与推理如何影响任务表现 | 固定任务与提示、基线、污染与成本 |
| 计算机视觉 | 图像、视频或三维结构中的信息如何被提取和利用 | 划分、标注、分辨率、逐类结果与域变化 |
| 多模态学习 | 不同模态如何对齐、融合并支持任务 | 单模态对照、配对质量、模态缺失与证据支持 |
| 生成模型 | 如何建模数据分布并控制生成过程 | 样本质量、多样性、条件一致性与采样预算 |
| Agent | 如何在工具与环境中完成多步任务 | 环境状态、任务成功、轨迹、重试与权限 |
| 强化学习 | 如何从反馈改进长期决策 | 交互与调参预算、独立评估、回报分布 |
| 世界模型 | 预测如何服务表示、规划和控制 | 多步误差与闭环任务效果分别评估 |
| 具身智能 | 感知与决策如何转化为物理动作 | 任务定义、控制条件、人工干预、泛化与迁移 |
| AI 系统 | 如何在质量约束下提高训练与推理效率 | 硬件、精度、吞吐、延迟分布、资源用量 |
| AI 与其他学科 | 如何回答具有领域约束的科学问题 | 领域基线、正确划分、测量限制与外部验证 |

各方向页的“如何设计一项可检验的研究”，与[实验方法](research-methods.md)和[数据集与评测](datasets.md)配套阅读。论文卡片是代表性工作的导读，不是完整历史、系统综述或重要性排名。

## 还应了解的基础与交叉主题

人工智能研究不只包括大模型与机器人。以下主题可以作为独立研究方向，也经常成为上述任务的方法基础。

- **[概率机器学习 · Kevin Murphy](https://probml.github.io/pml-book/)** — 英文教材系列。适合已有概率、线性代数和基本 ML 背景的学习者，系统理解概率建模、推断与学习。建议完成一个模型的假设说明、推导和小数据实验，而不是仅比较模型分数。
- **[图机器学习 · Stanford CS224W](https://web.stanford.edu/class/cs224w/)** — 英文课程。先掌握编程、概率和线性代数，再学习图表示及节点、边和图级任务。建议在规定划分下比较简单图特征与图神经网络；另见[图与时序资料](catalog-directions.md#topic-25)。
- **[时间序列学习 · sktime](https://www.sktime.net/)** — 英文官方文档与示例。适合已有 Python、统计与 ML 基础者学习预测、分类等时序工作流。建议先比较季节性或其他简单基线，采用符合预测时点的回测；未来信息不能进入训练期特征。
- **[因果推断 · Brady Neal](https://www.bradyneal.com/causal-inference-course)** — 英文课程与讲义，需概率基础。围绕潜在结果、因果图、混杂、识别和估计建立概念；建议写明一个因果问题的干预、假设和可识别条件。高预测精度本身不证明因果关系。
- **[公平性评估 · Fairlearn](https://fairlearn.org/main/user_guide/assessment/index.html)** — 英文官方指南。需分类与统计基础，用于学习按群体分解指标及评估前提。建议完成一份明确受影响群体和指标取舍的分析；单个公平性分数不能取代社会技术背景判断。

上述资源链接于 2026-10-16 查阅。课程是学习路径，工具文档是实现参考；两者均不替代原始研究证据。更多专题课程见[MOOC 与系统课程](courses.md)。

## 从研究方向到具体问题

选择一个结果可以检验的任务，列出两三个候选问题。逐项说明：已经知道什么，哪种比较或论证能够回答问题，需要哪些数据或数学假设。优先选择在现有条件下能够开展评价的问题，避免对整个领域作笼统判断。实证工作可从简单基线开始，理论工作可从明确命题和反例开始。

如果尚不能定义合理评价，先缩小任务或补充领域知识。研究问题应同时考虑兴趣、可获得的反馈、数据权限和实际预算。[学习路线](learning-path.md)提供阶段目标，[项目实践](start.md)提供小规模起步方案。
