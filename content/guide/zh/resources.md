## 课程与教材：先建立系统理解

[课程专页](courses.md)区分 MOOC 平台、大学课程、开放教材和官方实践教程，并按主题说明语言、先修能力和建议产出。另保留[基础资料目录](catalog-foundation.md)和[方向资料目录](catalog-directions.md)，方便按具体问题查找原始资料。

选择课程时核对大纲、教材、作业、学期与公开范围。公开视频、可下载讲义、自动评分作业和正式证书可能具有不同访问条件；不要把“可以访问课程主页”理解为所有内容都可免费使用。年份较早的优秀课程仍可用于基础学习，实现细节应配合当前版本文档。

[深度学习课程与论文精读](limu.md)连接《动手学深度学习》和论文讲解。观看视频时，配合代码实现和作业练习；只记录播放进度难以判断是否掌握概念。

## 练习与项目：区分训练目标

[练习专页](practice.md)按 Python 与算法、SQL、数学与机器学习、数据竞赛和工程训练分类。算法题训练局部问题求解，课程作业帮助将概念转化为实现，数据竞赛强调规定任务下的比较，研究项目还需要问题选择、证据设计与对局限的解释。

一次练习至少留下解题思路、复杂度或计算预算、失败原因，以及验证改进效果的记录。参考答案与 AI 辅助可以用于反馈，但应先尝试独立解释，并遵守课程和竞赛关于协作、外部数据与自动化工具的规则。

## 把资源组合为一个完整学习单元

以下是本指南提出的组合方式，按起点选一行即可；不要求同时开始所有路线。主课帮助建立知识结构，练习帮助发现理解中的不足，项目和报告则用于检验能否将所学用于新问题。

| 起点或目标 | 一组材料 | 产出与复查 |
| --- | --- | --- |
| Python 与编程基础 | CS50P 或北理工 Python + Exercism/力扣的一个专题 + 本地数据工具 | 输入校验、测试、复杂度与运行说明 |
| 经典 ML | ISLP 或 scikit-learn MOOC + 表格分类/回归项目 | 无泄漏 Pipeline、基线、验证选择和独立测试 |
| 深度学习 | D2L 或一门 DL 主课 + 一个小模型训练 | 梯度与状态检查、学习曲线、检查点和失败样本 |
| 专题研究 | 一门领域课 + 几篇直接相关的原始论文 + 一个受控复现 | 文献矩阵、假设、匹配条件与结论边界 |
| 工程或可信性 | 一项记录完整的基线 + 工程或可信 AI 案例分析 | 配置、不同条件下的结果、局限与维护决策 |

课程和平台名称可在[课程页](courses.md)与[练习页](practice.md)找到原始入口；选题与实验可结合[进阶专题](advanced-topics.md)、[实验设计示例](research-methods.md#worked-prediction)、[研究工程](engineering.md)及[可信 AI](responsible-ai.md)进一步展开。

## 数据、评估与研究材料

[数据集与评测](datasets.md)提供官方数据入口和基准说明，覆盖表格、视觉、语言、语音、图、检索、Agent、机器人与系统。先确认目标场景、数据许可、样本单位、划分方式和主指标，再选择实现。

[实验方法](research-methods.md)与[科研工具目录](catalog-research.md)用于组织实验、排查训练问题、控制比较条件、记录运行差异与发布复现材料。模型、软件、代码和数据各自可能有不同的版本与许可，应分别记录。

## 判断一份资源是否适合现在使用

增加新资源前，先回答三个问题：

1. **它能帮助解决什么问题？** 说出一个概念、任务或研究问题；优先定位对应章节，而不是再收藏一整门课。
2. **现在能否使用？** 核对先修能力、语言、字幕或文字替代材料、可用习题，以及算力与访问要求。开始资源需求较大的项目之前，也可以先用较小示例学习同一原理。
3. **怎样判断有收获？** 不依赖原材料解释一个概念、独立解答一道代表题，或指出论文主张的证据。解决当前问题后，回到主线继续。

## 资料选用与修订原则

新增课程、练习平台与数据资源的官方入口于 **2026-10-16** 进行了本轮核对；这不代表所有历史链接、课程作业或付费内容都已逐项访问。资源页注明的成果是本指南的学习建议，不是提供方承诺。

阅读时优先核查原始出处、资源类型、语言、先修要求、发布时间、版本与访问条件。将知识性解释、经验建议与尚无充分证据的判断分开记录。遇到失效链接、术语歧义或中英文含义不一致，可通过[指南仓库](https://github.com/OpenEnvision/ai_research_guide)提交具体页面、问题和替代来源。
