# 强化学习：从交互中学习

有些选择会改变接下来能看到什么、能做什么。游戏里现在拿到一小份奖励，可能错过后面的机会；机器人某一步动作也会影响后续能不能完成任务。强化学习研究怎样利用交互反馈学会行动。

策略根据当前观察选择动作，价值估计关心这些选择以后可能带来多少回报。游戏、机器人和语言模型后训练有不同的观察与动作，但都涉及怎样从反馈中改进策略。

<a id="rl-learning"></a>

## 先区分学习设置

可以先从小型马尔可夫决策过程学起，再理解回报与 Bellman 方程，随后学习价值方法和策略梯度。[Spinning Up 的核心概念](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)提供英文入门讲解。主要前置知识是期望、条件概率和梯度；机器人与大语言模型是应用，不是入门门槛。

| 区别 | 为什么重要 |
| --- | --- |
| 状态与观察 | 状态概括决定后续转移的信息，观察可能只揭示其中一部分，因此可能需要历史或记忆。 |
| 奖励与真实目标 | 被优化的反馈可能只是人们期望行为的不完善替代指标。 |
| 在线与离线 RL | 在线学习可以继续采集交互，离线学习使用固定数据集，动作覆盖受到限制。 |
| On-policy 与 Off-policy | 关注正在改进的策略与采集数据的策略之间的关系；Off-policy 不等于离线。 |
| 终止与截断 | 任务到达终止状态，与外部时间限制导致停止，可能需要不同的价值目标；见 [Gymnasium 的解释](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。 |

生成很长的推理过程，与通过奖励学习策略是两回事；多个 LLM Agent 协作，也不自动构成多智能体强化学习。

## 状态、动作与回报

环境提供观察，策略选择动作，环境随之变化并给出奖励。回报将后续奖励累积起来，表达一个动作对较长期结果的影响。[动手学强化学习](https://hrl.boyuai.com/)介绍这些概念及常见算法，[Gymnasium Basic Usage](https://gymnasium.farama.org/introduction/basic_usage/)展示观察、动作与奖励在程序中的交互接口。

奖励的定义决定训练鼓励哪些行为。稀疏奖励、延迟反馈和探索，会影响策略能否发现有效的动作序列。

## 价值估计与策略优化

价值学习估计某种状态或动作的长期回报，策略梯度直接优化策略的期望回报，Actor–Critic 则将价值估计与策略更新结合。DQN、PPO、SAC 等算法在这些思路下形成了不同的目标与数据使用方式。

回报目标的定义涉及概率与期望，参数更新则依赖梯度，相关内容见[数学与深度学习基础](basics.md)。[CleanRL](https://docs.cleanrl.dev/)提供常见深度强化学习算法的实现。

[Berkeley 深度强化学习课程](https://rail.eecs.berkeley.edu/deeprlcourse/)系统讲解深度 RL 方法；[Easy RL](https://github.com/datawhalechina/easy-rl)提供中文讲解与代码。

## 强化学习的主要研究方向

同样是根据反馈改进策略，语言模型输出的是 token，Agent 会调用工具，人形机器人要控制关节。这些方向共享一些算法，也有各自的数据、环境和评测方式。Model-based、离线学习等方法，又可用于不同的应用。

### 语言模型后训练：让回答更符合目标

模型已经会生成文字，接下来怎样让它遵循指令、解对题目？RL 可以用人类偏好训练出的奖励模型，也可以用答案或程序测试提供可验证的反馈。奖励的来源与训练方式，会影响模型表现出的行为。PPO 通过裁剪等机制限制过大的策略更新；[GRPO](https://arxiv.org/abs/2402.03300)利用一组回答的相对奖励构造优势估计，将策略优化用于语言模型训练。

- [InstructGPT](https://arxiv.org/abs/2203.02155)：将人工示范、偏好比较、奖励模型与策略优化结合。
- [DeepSeekMath](https://arxiv.org/abs/2402.03300)：提出 GRPO，比较其组内相对奖励的优势估计与依赖价值模型的方法。
- [DeepSeek-R1](https://arxiv.org/abs/2501.12948)：讨论推理任务的奖励设计，以及 R1-Zero 与 R1 的训练流程。
- [verl](https://github.com/verl-project/verl)：提供采样、奖励计算与策略更新的训练实现。更多模型报告见 [LLM 页](llm.md)。

### Agentic RL：学会在多轮交互中完成任务

Agent 的一次行动可能是搜索、执行代码或操作界面，工具返回的结果又会影响下一步。训练需要处理整段交互：哪一步带来了最终成功，错误怎样累积，模型是否学会了合理使用工具。

- [Search-R1](https://arxiv.org/abs/2503.09516)：把搜索接入推理过程，用 RL 学习何时检索、怎样利用结果；附[项目代码](https://github.com/PeterGriffinJin/Search-R1)。
- [RAGEN](https://arxiv.org/abs/2504.20073)：围绕多轮交互研究训练稳定性、环境反馈与策略学习。

沿着完整轨迹，分清模型生成的文字、环境提供的观察与奖励到达的时机。工具调用、交互数据与执行环境见 [Agent](agent.md)。

### 人形机器人：从运动控制到 Sim-to-Real

站稳、行走、跟随动作乃至全身协同，需要策略连续控制身体。训练常在仿真中进行，再迁移到真机；接触、延迟和动力学差异都会影响表现。观察量、动作表示、奖励与动力学建模，影响策略在仿真与现实中的行为。

- [Humanoid-Gym](https://arxiv.org/abs/2404.05695)：研究人形机器人运动控制中的仿真训练与零样本 Sim-to-Real 迁移。
- [ASAP](https://arxiv.org/abs/2502.01143)：通过对齐仿真与真实动力学，学习敏捷的全身动作。
- [Unitree RL Gym](https://github.com/unitreerobotics/unitree_rl_gym)：提供机器人配置、训练环境和部署代码。操作任务与 VLA 模型的相关研究见[具身智能](embodied.md)。

### Model-based RL

Model-based RL 学习环境怎样随动作变化，并利用这个模型训练策略或规划行动。模型可以在潜空间中产生想象轨迹，也可以参与执行时的动作搜索。

- [DreamerV3](https://arxiv.org/abs/2301.04104)：学习世界模型，并在想象轨迹中训练行为。
- [TD-MPC2](https://arxiv.org/abs/2310.16828)：学习用于控制的潜空间模型，并通过模型预测控制选择动作。

更广的预测、视频模拟与交互环境见[世界模型](world-model.md)。

### 离线 RL：从已有交互数据学习

当真机试错昂贵，或只能使用已经收集的数据时，就需要从固定数据集中学习策略。行为克隆直接模仿数据里的动作；离线 RL 还利用奖励与长期回报，但要处理策略偏离数据分布后的价值估计问题。

- [CQL](https://arxiv.org/abs/2006.04779)：通过保守的价值估计，减少对数据覆盖不足的动作的过高估计。
- [IQL](https://arxiv.org/abs/2110.06169)：通过隐式价值学习和优势加权的策略提取，减少训练时对分布外动作价值的依赖。

检查数据由哪些策略采集、覆盖哪些行为，以及怎样评估超出示范的改进。

### 多智能体 RL：多个决策者怎样协作

多个智能体同时行动时，每个个体看到的信息可能不完整，其他个体的策略也在变化。这涉及合作、竞争、通信和信用分配等问题；共享团队奖励时，怎样判断每个个体的贡献尤其重要。

- [MAPPO](https://arxiv.org/abs/2103.01955)：研究 PPO 在合作式多智能体任务中的表现，采用集中式价值估计与分散执行。
- [官方实现](https://github.com/marlbenchmark/on-policy)：包括环境接口、局部观察与全局信息的处理，以及多智能体训练代码。

LLM 多 Agent 系统也涉及协作，并可结合交互奖励训练策略。

## 怎样阅读奖励设计

选择一个已发表的任务，逐项理解奖励鼓励什么行为。设想策略可能怎样提高分数，却偏离真正目标；再结合作者记录的轨迹与成功判据解读奖励曲线。这项阅读练习不需要训练策略。

## 如何设计一项可检验的强化学习研究

- **研究问题与对照：** 明确环境、观察、动作、奖励、终止与截断，以及在线或离线设置。比较相同交互预算、调参预算与可用信息下的算法，而不是只对齐训练轮数。
- **评价协议：** 保留独立评估过程，记录环境版本、训练与评估种子、episode 数、回报分布和失败情形。报告交互量与实际运行成本；对跨任务结果写明归一化与聚合方式。
- **结论边界：** 奖励上升不必然意味着目标行为改善。检查奖励设计、投机行为和泛化；少数种子的优势不能自动外推到其他任务或机器人。
